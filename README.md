# HoldTracker

카메라로 칼리스테닉스 **정적 홀드**(플란체, 프론트 레버, 백 레버, L-sit, 핸드스탠드)를 자동으로 인식해서
**자세 품질을 점수화**하고 **유지 시간을 기록**하는 웹앱입니다. 진척도는 날짜별 그래프로 확인할 수 있습니다.

모든 처리는 브라우저 안에서(온디바이스) 이뤄집니다. **영상은 어디에도 전송되지 않고**, 기록은 기기의 localStorage에만 저장됩니다.

## 쓰는 법

1. 폰이나 PC 브라우저로 접속
2. 카메라를 **정확히 옆(측면)** 에 두고 전신이 프레임에 들어오게 거치
3. `카메라 시작` → 동작에 들어가면 자동으로 인식되고 타이머가 올라감
4. 자세가 무너지면 자동으로 종료되고 기록 저장 (기본: 자세 점수 72점 이상을 3초 이상)

폰에서는 **홈 화면에 추가**하면 앱처럼 전체화면으로 실행됩니다.

## 판정 방식

MediaPipe BlazePose로 33개 관절 랜드마크의 3D 좌표를 추출한 뒤, 규칙 기반으로 판정합니다.

| 신호 | 쓰임 |
|---|---|
| 손목 vs 어깨 높이 | 매달림(레버류) / 바닥 지지(플란체·L-sit·핸드스탠드) 구분 |
| 배 방향 법선 (몸통축 × 어깨선) | 프론트 레버 vs 백 레버 구분 |
| 발 높이 vs 손 높이 | 플란체 vs 푸시업 플랭크 구분 |
| 고관절/무릎 각도 + 발목 벌림 | 턱 / 어드밴스드 턱 / 하프 / 스트래들 / 풀 |

동작별 가중 점수(0~100):

- **플란체** — 수평 34% · 팔 폄 24% · 어깨 전방 이동 20% · 몸 일직선 22%
- **프론트/백 레버** — 수평 38% · 팔 폄 24% · 허리 처짐 14% · 몸 일직선 12% · 어깨각 16%
- **L-sit** — 몸통 수직 30% · 다리 수평 30% · 무릎 폄 24% · 팔 폄 16%
- **핸드스탠드** — 전신 수직 45% · 팔 폄 25% · 몸 일직선 30%

가중평균만 쓰면 한 항목이 크게 무너져도 통과하므로, **가장 나쁜 항목이 총점을 제한**합니다 (`총점 = min(가중평균, 45 + 55 × 최저항목)`).

타이머는 `IDLE → ARMING(안정화) → HOLDING → BREAKING(유예)` 상태머신이고, 기준 점수 ±8점 히스테리시스로 경계에서 시간이 튀지 않게 합니다.
**총 시간**과 **클린 시간**(기준 이상을 유지한 시간)을 따로 기록합니다.

## 알려진 한계

- 수평/수직을 화면 축 기준으로 재기 때문에 **카메라가 기울면 부정확** → 설정의 `수평 보정`으로 보정
- **측면 뷰가 필수**. 정면에서 찍으면 몸 기울기를 측정할 수 없음
- BlazePose는 서 있는 자세 위주로 학습되어 **거꾸로/수평 자세에서 랜드마크가 흔들릴 수 있음**
- 각도 임계값이 고정값이라 체형에 따라 편차가 있을 수 있음 (설정에서 기준 점수 조절 가능)

## 구성

단일 정적 사이트입니다. 빌드 과정이 없습니다.

```
index.html              앱 전체 (UI + 판정 로직 + 기록)
manifest.webmanifest    PWA 매니페스트
sw.js                   서비스 워커 (앱 셸 network-first, 모델 CDN cache-first)
icon-*.png              아이콘
```

로컬 실행:

```bash
python3 -m http.server 8777
# http://127.0.0.1:8777 접속
```

카메라 API는 보안 컨텍스트가 필요해서 `file://`로는 동작하지 않습니다. `localhost` 또는 HTTPS로 여세요.
